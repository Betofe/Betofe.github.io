Real-Time UAV Sensor Fusion — KF/ESKF on PX4 SITL

Built a real-time state estimation pipeline in C++ from the protocol layer up: a custom MAVLink v2 UDP parser (X.25 CRC, HIGHRES_IMU and GPS_RAW_INT decoding) feeding a 15-state Error-State Kalman Filter — position, velocity, orientation error, accelerometer bias, and gyroscope bias — with quaternion-based nominal-state propagation and error-state correction on GPS updates. Also implemented a standard Kalman Filter for comparison. Ran live against PX4 SITL and Gazebo on Ubuntu/WSL, logging raw sensor data against filtered output to CSV for direct accuracy validation. Several other filter formulations were also derived mathematically and implemented alongside these.
